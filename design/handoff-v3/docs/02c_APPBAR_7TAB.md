## 반응형 — 이름을 떼는 순서: 설정 → 타운맵 → 에디터

| 폭 | 마크 | 탭 | 세대 · 검색 · 테마 |
|---|---|---|---|
| ≥ 1360 | 36 + 워드마크 | 7개 아이콘 + 이름 | 지역명 포함 · 입력 240 · 36 버튼 |
| 1100–1359 | 36 + 워드마크 | 동일 | 입력 220 |
| 1024–1099 | 30만 | **설정 아이콘만** | "GEN n ▾" · 검색 아이콘 버튼 |
| 960–1023 | 30만 | **설정 · 타운맵 · 에디터 아이콘만** | 동일 |

근거: 자주 가는 네 화면(홈 · 도감 · 아이템 · 스쿼드)은 끝까지 이름을 지키고, 새 화면 둘과 설정이 먼저 아이콘이 된다. 아이콘만 남은 탭은 `aria-label` + 툴팁 필수.

## 키보드

탭 순서: 마크 → 탭 1–7 → 세대 → 검색 → 테마. 단축키 Ctrl+1…7, Ctrl+K(검색). 에디터 · 타운맵 본문이 없는 동안에도 탭은 활성이고, 본문 자리에 빈 상태("이 화면은 준비 중이에요")를 둔다 — 본문 디자인은 다음 요청.
