# CHANGELOG — 디자인 v2 → v3 (디자인 요청 0002 · 웹 재작성 기준)

## 화면 구성 결정 (사용자 결정 2026-10-26 반영)
- **v1 화면 체계로 복귀**: 엔트리 홈(세대 카드 9 · 최근 스쿼드 · 바로 가기) + 도감 · 아이템 · 스쿼드 · 설정. v2 인트로는 미사용(캔버스에 "(v2)"로 보관).
- 마크는 v2 **캡슐** 유지. 모든 화면의 앱 막대 마크를 캡슐로 통일.

## 다크 테마
- `darkOverrides` 11색 → **57키 완성**: 바뀌는 24(신규 토큰 `red.asText` · `danger.asText` · `glyph.ink` 포함) + "그대로" 19를 키로 명시.
- 상태 색 `darkStates` / `lightStates` 블록 신설 (호버 · 선택 · 눌림 · 포커스 · 비활성 · 탭 4상태).
- Qt판에서 확인된 문제 3건 해결: 사선 무늬 → `paper ↔ paper.stripe` 다크쌍(#1B1B21/#22222A), 틴트 6종 → 어두운 동색 바탕 + 밝은 글자, 세대 알약 → `yellow.tint` 다크(#3A3317).
- 대비표: 28쌍 계산 — 글자 조합 전부 4.5:1 이상, 미달 2건은 비활성 글자(예외)와 stat.high 채움(그래픽 3:1 통과). `docs/01c_DARK_CONTRAST.md`.

## 앱 막대 (SCR-00)
- 탭 5 → **7** (홈 · 도감 · 아이템 · 스쿼드 · **에디터** · **타운맵** · 설정). 새 아이콘 2종(세이브 카드 + 연필 / 접은 지도).
- **테마 스위치** 신설: 맨 오른쪽 36×36 아이콘 버튼 + 3항목 메뉴(라이트 · 다크 · 시스템).
- 검색 폭 280 → 240(1440) / 220(1100–1359). 아이콘만 남는 순서: 설정(1024) → 타운맵 · 에디터(960).
- 빨강 막대 위 포커스 링 = #FFE08A 3px 안쪽 (본문의 파랑 3px 규칙은 그대로).
- 에디터 · 타운맵 **본문 화면은 이번 범위 아님** — 탭과 빈 상태만.
