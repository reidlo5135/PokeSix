# PokeSix

포켓몬 세대별 정주행 보조 도구 — 도감 · 파티(SixSquad) 분석 · 아이템 · 세이브 뷰어.

**지금은 멀티 플랫폼 React(웹 · 데스크톱 · 모바일)로 처음부터 다시 만드는 중입니다.**
이전 구현(Qt 6 / C++20, v0.1.0–v0.5.1)은 [`qt6-final`](../../tree/qt6-final) 태그에 그대로 있고,
[Releases](../../releases)의 설치본도 계속 내려받을 수 있습니다.

- 스택: TypeScript · React · Vite · Electron(데스크톱) · Capacitor(모바일) · Vitest
- 디자인: [design/](design/README.md) 핸드오프의 팔레트 · 글꼴을 이어서 사용
- 데이터: [PokéAPI](https://pokeapi.co/) (비공식 팬 도구이며, 게임 에셋은 포함하지 않습니다)
