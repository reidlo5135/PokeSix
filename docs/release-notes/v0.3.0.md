PokeSix 0.3.0 — squad import now reads 5th-generation saves.

**Added**

- **Black · White and Black 2 · White 2 saves**: drop a BW or B2W2 `.sav` on the Squad screen (or use **Import**) and the party fills in, just like 4th-generation saves. The save alone tells which game it is — no setting to pick: each series is recognised by its own checksums, and the exact version (Black or White, Black 2 or White 2) by where the party was caught.
- 5th-generation details come along: the stored nature (gen 5 keeps it in its own byte rather than deriving it from the personality value), held items through the gen 5 item numbers, moves and abilities.
- The 5th-generation layout follows PKHeX's numbers and has been checked with test saves built from them, **not yet with a real BW or B2W2 save**. If one does not load, please open an issue with the game and region — the file itself is not needed.

**Changed**

- Save reading is organised per handheld (a DS reader holding the five DS series as table rows) instead of being written for one generation. 4th-generation saves read exactly as before.

No data rebuild: 0.2.x data carries over.
