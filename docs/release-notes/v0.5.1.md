PokeSix 0.5.1 — two fixes.

**Fixed**

- **Moves learned before evolving.** The Squad move picker only listed what the chosen Pokémon learns itself, so an Arcanine could not pick anything Growlithe learns on the way up. Earlier stages' level-up moves now appear as "Growlithe Lv 43", and the first stage's egg moves are offered to every stage. Moves like these in an imported save are no longer marked as unlearnable.
- **Generation 1 games.** The game chips showed six games because the Japanese Red and Blue duplicated the international ones. Generation 1 now shows four: Green · Red · Blue · Yellow.

No data rebuild: 0.5.0 data, squads and theme carry over.
