PokeSix 0.4.1 — one squad fix.

**Fixed**

- **Clear all** on the Squad screen could be undone by itself: after clearing a squad and switching to another game without adding anyone, coming back showed the old squad again. It happened to squads saved before each game got its own squad (for example one squad shared by FireRed · LeafGreen). The cleared squad now stays cleared.

No data rebuild: 0.4.0 data and squads carry over.
